# RiskFirewall AI — Security and Responsible Disclosure

This is a fabricated-data portfolio Prototype, not a production monitoring or
runtime-control service.

Please do not submit:

- real employee, customer, affiliate or reviewer information;
- wallet addresses connected to identifiable people;
- real agent-action, transaction, payment or investigation records;
- credentials, API keys or other secrets;
- allegations about a person or organization.

If you identify a code or evidence-integrity weakness, open an issue using a
minimal fabricated reproduction. Share security-sensitive details privately
with the repository owner rather than posting them in a public issue.
