# Bounded Agentic Control-Plane Simulation v0.3

## Purpose

Demonstrate one human-directed, workflow-executed, agent-ready assurance
control plane without replacing deterministic audit tests or accountable
human judgment.

This is a deterministic workflow simulation on the existing synthetic
commission case, not a third assurance domain, real Agent execution or an
autonomous auditor.

## Implemented loop

1. A human-authored Prototype mandate fixes scope, provisional thresholds,
   allowed tests, checkpoints and prohibitions.
2. A deterministic planning fixture proposes one registered procedure.
3. A self-attested human freeze binds the exact mandate and proposal hashes.
4. The workflow invokes the existing full-population commission test through a
   fixed allowlist.
5. A deterministic drafting fixture creates explanation sentences,
   investigation questions and unknowns. Every item cites source rows already
   bound to the exception.
6. The original append-only human review chain records accept, keep-open,
   close-with-explanation or escalation decisions.
7. A bounded, unsigned conclusion draft is derived from those human records
   only.

## Trust anchors

- The SQL tests, source snapshot, registered configuration and evidence pack
  remain deterministic and hash-bound.
- A changed mandate, plan, freeze record, threshold or configuration fails
  closed.
- Only `commission_full_population_v4` is allowlisted.
- Draft output cannot contain status, disposition, threshold, conclusion or
  signature fields.
- Every drafted claim, question and unknown requires non-empty source-row
  lineage within the exception boundary.
- Validated fixture inputs and outputs are retained for replay and bound to the
  corresponding drafts.
- Human review records remain the only source of exception dispositions.
- The conclusion draft is always unsigned and never an automated audit
  opinion.

## Provider boundary

v0.3 permits only `deterministic_fixture` version 1. No external model, API,
secret or network service is used. The fixture proves the control plane and
replay contract; it does not establish real Agent execution, model behavior,
accuracy, citation quality or resistance to natural-language prompt
injection.

A future external-model trial would require an Owner decision on provider,
cost, data handling, retention and acceptable evaluation criteria. It must use
the same schema and may not enter the deterministic detection or decision
path.

## Human authority

The self-attested Prototype records demonstrate process shape only. They are
not authenticated identities, external timestamps, production approvals or an
audit signature.

Humans remain responsible for:

- scope, materiality and thresholds;
- freezing the exact plan;
- evaluating each exception and additional evidence;
- accepting, modifying or rejecting drafted language;
- signing any final workpaper or assurance conclusion.

The worked review fixtures in this version demonstrate exception disposition
only. They do not record authenticated human acceptance, modification or
rejection of the drafted language.

## Explicit non-goals

No real employee data, external LLM, external Agent executor, dynamic code
generation, arbitrary SQL, automatic exception closure, automatic threshold
tuning, evidence authentication, production action, autonomous auditor or
signed audit opinion.
